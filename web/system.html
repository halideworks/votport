Maintenance & verification

Drain for restart

Refuses new upload sessions with a transient error so active ones finish first; downloads and admin stay available. Restart once votport_sessions_active on /metrics reads 0, then turn it off. Uploads also survive a restart on their own; drain is for a zero-surprise upgrade.

Receipt verification

Every received file carries a signed .vot-receipt sidecar. Anyone can check one at /verify against this public key.

Backups

Status

Loading backup status…

Restore replaces current application state and restarts the supervised service. Current application state will be replaced, the cookie secret will rotate, and every existing admin session will be signed out. Automatic backups will remain disabled until an admin re-enables them.

Schedule

Automatic snapshots contain the database and VOTPort-managed identity files only. Received and outbound files remain separate operator backups.
