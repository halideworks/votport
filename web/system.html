Sign-in

Group changes at the identity provider take effect at the next sign-in, so this bounds offboarding latency. The local break-glass session is fixed at 7 days.

Provisioning endpoint: /scim/v2. Tokens are stored hashed; saving a new one keeps the previous one valid until it is cleared, so the provider can be moved without a gap. A deactivated or deleted user is revoked here; userName must equal the claim named by VOTPORT_OIDC_SUBJECT_CLAIM. With provisioning required, a subject with no SCIM or prior sign-in row cannot sign in; the local password is unaffected.

Maintenance & verification

Standby replica

A standby started with votport standby pulls this instance's database and identity files with this token and keeps them staged as its next boot's restore. Stored hashed.

Drain for restart

Refuses new upload sessions with a transient error so active ones finish first; downloads and admin stay available. Restart once votport_sessions_active on /metrics reads 0, then turn it off. Uploads also survive a restart on their own; drain is for a zero-surprise upgrade.

Receipt verification

Every received file carries a signed .vot-receipt sidecar. Anyone can check one at /verify against this public key.
