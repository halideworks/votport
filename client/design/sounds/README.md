Original votport completion chime, released under the repository license.

Still water: a soft G4, B4, D5 chord with a slow attack and fading tail.
The notes begin 45 ms apart, with a 110 ms attack and 500 ms exponential
decay. Mono PCM, 48 kHz, 16 bit, 2.4 seconds, peak -16 dBFS. Both native
apps use this same asset through their notification system so OS sound
settings still apply.
