Original votport completion chime, released under the repository license.

A soft C5 and G5 pair, 160 ms apart, with an 18 ms attack, 360 ms exponential decay, and quiet second and third harmonics. Mono PCM, 48 kHz, 16 bit, 2 seconds, peak -16 dBFS. Both native apps use this same asset through their notification system so OS sound settings still apply.
